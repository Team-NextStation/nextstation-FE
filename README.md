# 환승여행
##  매일 지나치던 지하철역이 오늘의 여행지로,

환승여행은 익숙한 지하철역을 새로운 여행 출발점으로 바꿔, 사용자가 일상 속에서 가볍게 새로운 장소와 코스를 발견할 수 있도록 돕는 서비스입니다.
직접 코스를 만들고, 추천 코스를 둘러보고, 여행 기록을 남기며 나만의 도시 여행을 쌓아갈 수 있습니다.

## 서비스 소개
반복되는 일상 속에서 스쳐 지나가던 역을 여행지로 바라보면, 도시가 조금 다르게 보입니다.
환승여행은 지하철역 기반으로 장소와 코스를 탐색하고, 사용자의 취향에 맞는 여행 경험을 제공하는 웹 서비스입니다.

## 핵심 기능
- 역 기반 여행 코스 탐색
- 조건/취향 기반 코스 추천
- 직접 여행 코스 생성 및 저장
- 카카오 로그인 지원
- 여행 로그 및 기록 작성
- 장소 상세 정보 및 지도 확인

## 프로젝트 구조
```bash
src/
  api/        # API 통신 로직
  assets/     # 이미지, 아이콘, 애니메이션 리소스
  components/ # 공통 컴포넌트
  pages/      # 페이지 단위 UI
  types/      # 타입 정의
  utils/      # 공통 유틸 함수
```
